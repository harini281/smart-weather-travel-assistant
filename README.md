# 🌦️ AI Weather Assistant

An intelligent weather assistant powered by AI that delivers real-time weather updates with smart conversational responses. Built using React and Gemini AI to create a modern and interactive user experience.

---

## 📌 Overview

AI Weather Assistant allows users to search for weather information by city name and receive AI-generated responses alongside real-time weather data. The application combines weather APIs with generative AI to create a more engaging forecasting experience.

---

## ✨ Features

- 🌍 Search weather by city
- 🤖 AI-powered weather explanations
- ⚡ Real-time weather information
- 📱 Responsive and user-friendly interface
- ⏳ Loading and error state handling
- 🔄 Dynamic API integration
- 🎨 Clean modern UI

2. Weather API fetches real-time weather data
3. Gemini AI processes and generates intelligent responses
4. Results are displayed in an interactive interface
